Data Structures · your college material
What's the difference between a singly and doubly linked list?
A singly linked list node stores data and one pointer to the next node, so you can only move forward. A doubly linked list adds a second pointer to the previous node — you can traverse in both directions, at the cost of extra memory per node.
Chapter 3 · Linked Lists · page 7
When would I prefer a doubly linked list?
When you often delete a node given only its reference, or need to walk backwards — an LRU cache or browser history, for example. The back-pointer makes those operations O(1) instead of O(n).
