Authentication flows

Every account in Project K is created by an administrator — there is no public sign-up. New users set their own password from a single-use activation link.

Sign in
Tenant-aware login. Fail three times to see the lockout state.
Activate account
First-login flow from an emailed invite link.
Forgot password
Non-enumerating request, then a single-use link.
Reset password
Live policy meter matching the backend rules.
